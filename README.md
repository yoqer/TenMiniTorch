# TenMiniTorch


TenMiniTorch es una librería PyTorch, con facultad final de Tensorflow y compresión de modelos Mini, para placas IoT. 

Es una librería limpia y minima sin mayor funcionalidad que para Refourcing Learning,  Fine-Tuning; Entreno, Re-Entreno; e Inferencia. 
Por lo que puede requerir otras librerias externas para acciones.

Es ideal como la base del desarrollo de herramientas de Refourcing Learning para LLM, Robótica, Web 4.0, Creacion, Automatización, Aprendizaje Orientado a Objetos y IoT.
